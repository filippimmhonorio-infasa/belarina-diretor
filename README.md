# Belarina Precificador — PWA

App web instalável (PWA) para precificação de derivados de milho.
Funciona offline, instala na tela inicial do celular sem APK.

---

## Como publicar no GitHub Pages (gratuito)

### 1. Criar conta no GitHub
Acesse https://github.com e crie uma conta gratuita se ainda não tiver.

### 2. Criar repositório
- Clique em "New repository"
- Nome: `belarina-precificador`
- Marque "Public"
- Clique em "Create repository"

### 3. Fazer upload dos arquivos
- Clique em "uploading an existing file"
- Arraste todos os arquivos desta pasta (index.html, manifest.json, sw.js, icon-192.png, icon-512.png)
- Clique em "Commit changes"

### 4. Ativar GitHub Pages
- Vá em Settings → Pages
- Source: "Deploy from a branch"
- Branch: main → / (root)
- Clique em Save

### 5. Acessar o app
Em 2-3 minutos o app estará disponível em:
https://SEU_USUARIO.github.io/belarina-precificador

---

## Como instalar no celular Android

1. Abra o link no **Chrome**
2. Toque no menu (⋮) → "Adicionar à tela inicial"
3. Confirme — o ícone da Belarina aparece na tela inicial
4. Funciona offline após a primeira visita

## Como instalar no iPhone

1. Abra o link no **Safari**
2. Toque em Compartilhar (□↑) → "Adicionar à Tela de Início"
3. Confirme

---

## Como atualizar o app

Basta editar o `index.html` no GitHub diretamente pelo navegador.
Os celulares recebem a atualização automaticamente na próxima abertura.
